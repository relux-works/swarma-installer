# Book mapping

One table, round 4. Each row is one installer decision of this package, the source that covers it, and a mark.

- **same**: the source already says it; this package adds nothing.
- **refines**: the source says it more broadly; the note says what this package narrows. A refinement never contradicts its source.
- **conflicts**: sources disagree, or a source and a ruling disagree. Where a ruling now decides the point, the note cites the ruling and says which side holds; where a book loses on colony1, the row names the deviation of the test profile (`TP-..` in file 4). Where nothing decides it, the row points to an open decision (`OD-..` in file 5).
- **new**: no source covers it; the note says why.

Sources and their pins (from the reference pin list):

- **IB**: swarma-docs, `install-book/ru`, chapters `00` to `07`, commit `942a07f12e478841c483a624e94dc47100bb7571`.
- **SB**: swarma-docs, `book/ru`, the same commit.
- **RS**: the release standard, commit `78fd6e62273309c67224daececf750618d5c9544`.
- **UM**: swarma-user-manager, `spec/`, commit `04fe2b767ebbce15a4d2e7fa3b11738c41856609`.
- **DS**: swarma-dispatcher, `spec/m0-launch.md` and `spec/transport.md`, commit `85a47091632d2b7cb5888406a2f0a585e9ff5b63`.
- **HK**: hooks text r2.16, last section only (deployment), sha256 prefix `1ff91660`.
- **MAP**: platform map of 2026-11-16, sha256 prefix `a981d12f`. Where the map contradicts a book, the book wins.

Rulings, by the short names used in the notes:

- **ruling OD-n**: row n of the lead's rulings (OD-1 to OD-14 on round 1; OD-15 to OD-22 after round 2).
- **ruling TRUST**: the later ruling that withdraws "interim trust root = a key held by automated sessions": the installer trusts only the set digest the owner approved in person.
- **ruling ROOT-COPY**: the ruling on the first read's blocking finding: root itself checks the approved digest on a root-owned copy; the digest reaches root through the owner's administrator session.
- **ruling SESSION**: colony1's first step uses a tmux session per agent with the a2a hooks under the agent's own station account, not the product session host.
- **ruling BRIDGE**: agents send only through the bridge's local submit endpoint; no agent account holds a carrier credential.
- **owner decisions**: the repository (OD-1), the final trust root (the offline publisher key, fingerprint in the install command), who runs the root steps (OD-3), the model account (OD-4), and the macOS home rule.
- **answers**: the owners' answers on the MISSING checklist (dispatcher, a2a, the co-owner's side for the session host, Keymaker, and the user manager owner's rows on its launcher, stop operation and unbuilt units).

Section names of IB and SB are English translations of the Russian headings; the file name identifies the chapter. The chapter numbers of SB at this pin are the file numbers (`04-principy`, `05-polzovatel-i-set`, `06-klyuchi`, `07-zapusk-i-host-sessiy`, `08-curator`, `09-uchetnye-dannye`, `12-interfeysy`, `15-keeper`, `24-soobscheniya-i-most`).
